# Changelog

## 0.1.1 — 2026-08-21

- 移除刻度条上的原生 `title` 属性，消除浏览器默认提示框（只保留左侧自定义摘要提示）。
- hover 高亮更柔和：降低背景透明度，去掉生硬的白色描边与投影，改用主题色细边框。
- 底部消息数量改为圆角胶囊 chip（浅底 + 细描边 + tabular 数字），并与轨道底边留出间距。

## 0.1.0 — 2026-08-21

- 首个版本：DSH 对话右侧快速导航条。
  - 在聊天区右缘渲染竖向迷你导航（类似手机通讯录快速索引）。
  - 每个用户/AI 消息一个可点击圆点，位置与消息在滚动内容中的比例一致。
  - 点击圆点跳转到对应消息；在轨道上按住拖动可快速滚动。
  - 当前视口消息高亮（品牌色放大），悬浮圆点显示消息首行摘要。
  - 底部显示消息总数徽标。
  - 纯 client DOM 注入，MutationObserver 自愈，不改 DSH 源码。
